# Run doc — Shree Ram website (Next.js 14)

## 1. Reproduce the uncommitted artifacts (fresh checkout)

Everything needed is generated from committed files — no env files to copy:

```bash
npm install                 # dependencies (package-lock.json)
npm run build               # prebuild regenerates .content/generated.ts + placeholder SVGs
```

- `.content/generated.ts` — generated by `scripts/generate-content.js` (validates + barrels the JSON in `/content`). Rebuilt automatically by `predev`/`prebuild`.
- `public/media/**/*.svg` — neutral labelled placeholders generated by `scripts/generate-placeholders.js` from `content/media.manifest.json`. Rebuilt automatically.
- No `.env.local` in Phase 1. Owner settings live in `config/site.config.js` (GA4/Clarity IDs, domain, Google review URL) and `config/whatsapp.config.js` (WhatsApp numbers).

## 2. Run the server

Production (what the Preview tab serves):

```bash
npm run build
npm run start               # http://localhost:3000
```

Live-reload development:

```bash
npm run dev                 # http://localhost:3000  (content validated on each start)
```

Port 3000 is the default. If taken, use `-p 3001` on the `next` invocation (scripts in package.json).
