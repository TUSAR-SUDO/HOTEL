# Shree Ram — Hotel & Lodge Website (Phase 1)

Frontend-only website for **Hotel Shree Ram, Puri** and **Shree Ram Lodge, Bhubaneswar**,
built to the Project Documentation v1.0. WhatsApp click-to-chat is the booking engine;
a backend plugs in later without UI rewrites (all content is JSON-driven).

## Run it

```bash
npm install
npm run dev        # http://localhost:3000  (content is validated on each start)
npm run build      # production build
```

## Pages

`/` · `/puri` · `/bhubaneswar` · `/rooms` · `/gallery` · `/explore` · `/offers` ·
`/contact` · `/policies` · `/review` (QR target, redirects to Google reviews when configured)

## The owner's four how-tos

### 1. Change WhatsApp numbers
Edit **one file**: `config/whatsapp.config.js`. Set each property's `number` in
international format without `+` or spaces (e.g. `919337592943`). Every button on the
site reads from this file. Also confirm which number is WhatsApp-enabled per property.

### 2. Add or edit rooms
Edit `content/rooms.json`. Each room:

```json
{
  "property": "puri",              // "puri" or "bhubaneswar"
  "id": "puri-deluxe-ac",          // unique
  "name": "Deluxe AC Room",
  "size": "180 sq ft",
  "bed": "1 queen bed",
  "ac": true,
  "maxGuests": 3,
  "priceFrom": 1500,               // number, or null to show "Price on request"
  "facts": ["AC", "Attached bathroom"],
  "amenityIds": ["ac", "wifi"],
  "description": "20 words max",
  "imageId": "puri-room-deluxe-1"  // must exist in media.manifest.json
}
```

Run `npm run dev` — a build-time validator catches typos (unknown property, missing
image, wrong phone format) and tells you the exact line.

### 3. Swap photos & videos (placeholders → real)
Drop real files into `public/media/puri/` and `public/media/bhubaneswar/`, then edit
**one file**: `content/media.manifest.json` — change each item's `src` (e.g.
`/media/puri/hero-exterior.jpg`), `alt`, `w`, `h`. Placeholder frames are generated by
`scripts/generate-placeholders.js` and are clearly labelled; they disappear automatically
when `src` no longer ends in `.svg`. For the hero video, set `type: "video"`, `src`,
and a `poster`.

**Photos already in place (Bhubaneswar):** real photos of Shree Ram Lodge
(`real-1.jpg` … `real-6.jpg`: rooms, reception, night frontage, entrance, corridor)
were taken from the property's Justdial listing and are wired into
`content/media.manifest.json`. Replace them any time with higher-quality shoot photos by
editing the same manifest entries. Puri still uses themed placeholder artwork.

**Logo:** the master file is `SR LOGO.png` in the project root. Web-ready copies
(`public/sr-logo-192.png`, `public/sr-logo-512.png`, `app/icon.png`, `app/apple-icon.png`)
are resized from it with `powershell` System.Drawing. If the master's orientation ever
looks mirrored in the UI, regenerate with a `RotateNoneFlipX` pass (see git history).
Raster photos (jpg/webp/png) are optimized automatically by `next/image`; vector artwork
stays as SVG for full-resolution rendering.

### 4. Edit festival banners
In `content/properties.json`, under the property's `festivalBanner`:

```json
"festivalBanner": {
  "enabled": true,
  "title": "Rath Yatra: book early",
  "text": "Festival week fills fast. Message us to lock your room.",
  "cta": "Ask about festival dates"
}
```

Set `enabled: false` to hide it. Same pattern for seasonal notices in `content/offers.json`.

## Other owner settings

| What | Where |
|---|---|
| Google review link (for `/review` QR) | `config/site.config.js` → `googleReviewUrl` |
| GA4 / Microsoft Clarity IDs | `config/site.config.js` → `ga4Id`, `clarityId` |
| Final domain (SEO, sitemap, OG) | `config/site.config.js` → `url` |
| Prices | `content/rooms.json` → `priceFrom` |
| Distances (verify on Maps first!) | `content/properties.json` → `distanceChips` |
| Amenities (only real ones) | `content/properties.json` → `amenities` |
| Real Google reviews | `content/reviews.json` (section stays hidden while empty) |
| Policies | `content/policies.json` |

## Honest-data rules (do not break)

- Every unknown value is marked `TODO_CLIENT_CONFIRM` in the JSON. Search the `/content`
  folder for that string before launch and replace or remove each one.
- The Guest Voices section renders **only** when `content/reviews.json` has real reviews.
- Distances show as "TODO: verify on Maps" until real values are entered.
- No stock photos: placeholders are neutral labelled frames.

## Tech

Next.js 14 (App Router) · TypeScript · Tailwind CSS · Lucide icons.
Content pipeline: `npm run dev`/`build` runs `scripts/generate-content.js` (validates and
generates `.content/generated.ts`) and `scripts/generate-placeholders.js`.
